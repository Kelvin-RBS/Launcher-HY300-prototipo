# Jogos do RetroArch

Pasta reservada para os jogos que o launcher abre pelo RetroArch.

```
jogos/
  snes/        Super Nintendo  (.sfc, .smc, .swc, .fig)
  megadrive/   Mega Drive      (.md, .gen, .smd, .bin)
```

- **Os jogos nunca vão para o GitHub:** o `.gitignore` bloqueia tudo dentro de `snes/` e `megadrive/`. Não os publique.
- Use apenas jogos que você tem direito de usar.
- Para copiar para o projetor: `scripts/05-enviar-jogos.ps1` (veja `docs/14-jogos-no-launcher.md`).
- No projetor, os jogos ficam em `/storage/emulated/0/Jogos/`.
